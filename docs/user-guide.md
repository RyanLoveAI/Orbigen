# 构件功能指南

## 本地素材管理

从「素材库」导入模型，核对预览、分类、比例及贴图，再用于装配。需要 Blender 的格式转换，须先配置本机 Blender。导入成功不代表素材已通过美术、性能或版权验收。

## 参考图分拆与四视图

先在「渲染图分拆」记录需要制作的组件。给单个组件准备一致的前、左、后、右视图，保持比例、背景和朝向一致。四视图不是把四张图拼成一张图。

## Tripo AI 3D 生成

连接国际官方 API Key 后，可选文字、单张参考图或多视图。多视图至少两张不同图片，且必须包含前视图。文字提示词最多 1024 个字符。

目前适配 H3.1。按需要选择几何质量、贴图质量、三角面／四边形及面数上限，核对参考积分估算后提交。四边形结果使用 FBX，经本机 Blender 转为预览 GLB。

任务完成后自动下载入库。提交超时或结果不明时，先到官方控制台核对任务，避免再次提交。可用官方任务 ID 找回任务。旧站记录只作为历史保留，不会用官方 Key 重提。

## 图片文件夹批量生成

选择图片目录，扫描后检查清单和积分估算，再启动。四视图批量模式采用每个子文件夹一件组件的目录结构，视角文件可使用 front、left、back、right 名称。单图模式按图片逐件生成。

暂停队列只停止后续提交；已提交的云端任务仍可能继续。请先用少量素材验证设置，再处理大批量。

## 程序化树木制作

进入「树木制作」，依次检查叶片、树干、枝条及整树。保存自己的组件并复用，调整精度与面数预算后导出。使用源码版缺失的植物预设前，先阅读 [素材边界](../ASSETS.md)。

## 建筑构件装配

从素材库选择构件，调整位置、旋转和尺寸，保存工程或半成品。进入游戏引擎前，另行验收材质、碰撞、LOD、风动和运行性能。
